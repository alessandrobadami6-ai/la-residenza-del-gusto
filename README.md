# La Residenza del Gusto – sito web

Sito della trattoria **La Residenza del Gusto** (Via Vigalfo 14, Albuzzano – PV).

- Tutto il sito è in un unico file: `index.html` (si apre con un doppio clic, nessun server necessario).
- **Menù del giorno**: si aggiorna nello script in fondo a `index.html`, nell'oggetto `MENU`.
- **Foto**: vanno inserite nell'oggetto `FOTO`; finché mancano si vedono illustrazioni provvisorie.

## Pubblicazione con GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → branch `main`, cartella `/ (root)`.
