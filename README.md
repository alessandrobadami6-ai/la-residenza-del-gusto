# La Residenza del Gusto – sito web

Sito della trattoria **La Residenza del Gusto** (Via Vigalfo 14, Albuzzano – PV).

- `index.html`: tutto il sito (si apre con un doppio clic, nessun server necessario).
- `assets/`: logo e foto usati dal sito.
- **Modulo eventi**: per attivare l'invio email, sostituire `INCOLLA-QUI-LA-CHIAVE-WEB3FORMS` in `index.html` con la chiave di accesso di [Web3Forms](https://web3forms.com).

## Pubblicazione con GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → branch `main`, cartella `/ (root)`.
